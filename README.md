# SkillMatch JS

## Sobre o projeto

O SkillMatch JS é um simulador de compatibilidade entre uma pessoa candidata e vagas fictícias de Front-End Júnior.

O sistema analisa as habilidades do candidato e compara com os requisitos das vagas, mostrando:

- percentual de compatibilidade;
- classificação da compatibilidade;
- habilidades que o candidato possui;
- habilidades faltantes;
- vaga mais compatível;
- recomendação de estudos.

O projeto foi desenvolvido utilizando JavaScript puro com foco na prática dos conteúdos estudados durante o Módulo 01 no curso de Programação Front-End React.

---

## Objetivo

Praticar os principais conceitos fundamentais de desenvolvimento Front-End utilizando JavaScript, lógica de programação e organização de projeto.

## Funcionalidades

- Cadastro de candidato;
- Listagem de vagas fictícias;
- Análise de compatibilidade;
- Classificação das vagas;
- Identificação de habilidades faltantes;
- Recomendação de estudos;
- Simulação assíncrona utilizando Promise e async/await;
- Uso de Programação Orientada a Objetos (POO).

## Como executar o projeto

O projeto pode ser executado diretamente no console do navegador.

### Passo a passo

1. Abra o Google Chrome;
2. Pressione `F12` ou `Ctrl + Shift + J`;
3. Abra a aba `Console`;
4. Copie o conteúdo do arquivo `skillmatch.js`;
5. Cole no console;
6. Pressione `Enter`.

## Como a internet funciona

A internet funciona através da comunicação entre clientes e servidores.

O cliente realiza uma solicitação e o servidor responde enviando informações, como páginas, dados ou arquivos.

Neste projeto, o uso de `Promise` e `async/await` simula o carregamento assíncrono de dados como acontece em aplicações reais.

---

## Arquitetura cliente-servidor

Na arquitetura cliente-servidor:

- o cliente é responsável pela interface e solicitações;
- o servidor processa as informações e retorna os dados.

Neste projeto, foi simulada uma busca de análises de vagas utilizando JavaScript assíncrono para representar esse comportamento.
